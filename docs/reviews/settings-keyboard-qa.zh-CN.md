# 设置页键盘可访问性检查清单（简体中文）

在设置相关 UI 或文案变更后使用。仅键盘，不使用鼠标。

## 焦点与 Tab 顺序

- [ ] Tab 按合理视觉顺序移动（供应商 → 推理 → MCP → 技能 → 插件 → 日历 → 天气 → 隐私）。
- [ ] Shift+Tab 可反向且无焦点陷阱。
- [ ] 每个可交互控件（含自定义开关）均有可见焦点样式。
- [ ] 禁用控件被跳过，或聚焦时能明确感知为禁用。

## Escape 与弹层

- [ ] Escape 关闭最上层对话框/弹出层，且焦点不残留在已卸载节点。
- [ ] 关闭后焦点回到打开该层的控件。
- [ ] 嵌套对话框每次 Escape 只关闭一层。

## 可滚动对话框

- [ ] 仅用键盘可到达折叠区域下方的控件。
- [ ] 焦点控件会被滚动到可视区域内。

## 语言与动效

- [ ] 切换界面语言后焦点仍在等价控件，Tab 顺序不乱。
- [ ] 开启减少动态效果时，过渡动画不阻碍键盘操作。

## 隐私与敏感操作

- [ ] 隐私相关选项可纯键盘切换。
- [ ] 破坏性操作的确认框可键盘到达并关闭。
