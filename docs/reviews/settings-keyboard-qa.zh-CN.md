# 设置页键盘可访问性检查清单（简体中文）

在设置相关 UI 或文案变更后使用。仅键盘，不使用鼠标。请先在桌面默认尺寸（1440×940）完成整套
检查，再在支持的窄尺寸（900×680）复查；英文和简体中文各跑一遍。使用合成或未连接状态即可，
不需要供应商 Key、私有 Vault、位置权限或外部服务。

## 焦点与 Tab 顺序

- [ ] 从侧栏开始时，“设置”有清楚的焦点样式，Enter/空格可打开设置，焦点不会落入隐藏内容。
- [ ] 设置页签行只有一个 Tab 停靠点；方向键按视觉顺序激活“个人 → 模型 → 知识库与数据 → X 情报 → 扩展 → 高级 → 关于与更新”。
- [ ] Tab 只进入当前设置面板内的控件，并按视觉顺序移动。
- [ ] Shift+Tab 可反向且无焦点陷阱。
- [ ] 每个可交互控件（含自定义开关）均有可见焦点样式。
- [ ] 禁用控件被跳过，或聚焦时能明确感知为禁用。
- [ ] 在 900×680 下，重排不会改变逻辑顺序，也不会把当前焦点藏到屏幕外。

## Escape 与弹层

- [ ] Escape 关闭最上层对话框/弹出层，且焦点不残留在已卸载节点。
- [ ] 关闭后焦点回到打开该层的控件。
- [ ] 没有对话框打开时，Escape 不会关闭设置页或丢弃正在编辑的字段。

## 可滚动对话框

- [ ] 仅用键盘可到达折叠区域下方的控件。
- [ ] 焦点控件会被滚动到可视区域内。

## 语言与动效

- [ ] 切换界面语言后仍停留在设置和当前页签；焦点回到等价控件或当前页签，不能掉到文档 body。
- [ ] 开启减少动态效果时，过渡动画不阻碍键盘操作。

## 隐私与敏感操作

- [ ] 隐私和联网相关选项可纯键盘切换；禁用操作会说明不可用原因。
- [ ] 审阅或确认对话框可键盘到达，初始焦点有标签，并可在不执行动作的情况下关闭。
- [ ] 整套检查不会要求或保存真实供应商 Key、Vault 路径、位置权限或外部账号连接。
