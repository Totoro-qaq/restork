# Restork 中文投稿材料

## 1. 作品名称与介绍

**作品名称：Restork——查资料，学知识，推进工作**

Restork 是一款免费、开源的桌面应用，把研究、学习和日常工作放在同一个本地工作台里。它可以检索你主动选择的 Markdown 知识库，查找公开资料并保留出处，也可以根据已有笔记安排学习、整理任务、起草日报周报和演示文稿。报告与演示文稿支持填写具体要求、选择模型和内置版式，生成后可以逐页预览，再下载 Markdown、PPTX 或 PDF。

我不希望它拿到一个目标就直接修改文件。Restork 会先展示准备写入的内容；只有确认当前版本后才会保存。接入的 MCP 工具运行在操作系统沙箱中，并限制可访问的文件、网络、运行时间和输出大小。API Key 存在系统凭据库里，不进入网页界面。

项目使用 Rust、Tauri 和 TypeScript 开发，采用 MIT 许可证。当前提供 macOS、Windows 与 Linux 桌面构建，仍处于技术预览阶段。我希望它能帮助经常查资料、写笔记、做报告的研究者、开发者和知识工作者，同时也把本地应用如何处理模型、工具和文件写入的过程公开出来，供社区一起改进。
