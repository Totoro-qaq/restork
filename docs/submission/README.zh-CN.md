**Restork**

### 作品介绍（推荐版）

Restork 是一款免费、开源的桌面应用，把研究、学习和日常工作放在同一个本地工作台里。它可以检索你主动选择的 Markdown 知识库，查找公开资料并保留出处，也可以根据已有笔记安排学习、整理任务、起草日报周报和演示文稿。报告与演示文稿支持填写具体要求、选择模型和内置版式，生成后可以逐页预览，再下载 Markdown、PPTX 或 PDF。

我做 Restork，是因为查资料、学知识和推进工作往往不是三件分开的事：一次技术调研可能会变成学习笔记、待办事项、周报，最后还要整理成演示文稿。与其在多个工具之间反复复制内容，我更希望这些结果能够沿着同一条记录继续使用，也能在需要时回到原来的资料和出处。

Restork 不会拿到目标后直接修改文件。准备保存什么、改动哪一处，会先展示出来；只有确认当前版本后才会写入。接入的 MCP 工具运行在操作系统沙箱中，并限制可访问的文件、网络、运行时间和输出大小。API Key 保存在系统凭据库，不进入网页界面。

项目使用 Rust、Tauri 和 TypeScript 开发，采用 MIT 许可证。当前提供 macOS、Windows 与 Linux 桌面构建，仍处于技术预览阶段。我希望它能帮助经常查资料、写笔记、做报告的研究者、开发者和知识工作者，同时也把本地应用如何处理模型、工具和文件写入的过程公开出来，供社区一起改进。

### 作品介绍（短版，字数有限时使用）

Restork 是一款免费、开源的桌面应用，用来查资料、学知识和推进工作。它可以检索用户主动选择的 Markdown 知识库，整理带出处的研究结果，根据已有笔记安排学习，并把运行记录继续做成任务、日报周报或演示文稿。文件写入前会先展示具体内容，API Key 留在系统凭据库，MCP 工具在操作系统沙箱中运行。项目使用 Rust、Tauri 与 TypeScript 开发，支持 macOS、Windows 和 Linux，目前处于技术预览阶段。
