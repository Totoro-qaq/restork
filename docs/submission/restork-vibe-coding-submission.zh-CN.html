查资料，学知识，推进工作。

Restork 把本地 Markdown、公开资料、模型和日常任务放进同一个桌面工作台。写入前先看具体内容，确认后再保存。

RESEARCH + STUDY + WORK

一天里的资料、学习和工作，本来就会交织在一起。

Restork 不把它们拆成三个互不相干的助手，而是共用你选择的文件、模型、任务和运行记录。

RESEARCH

查资料，保留出处

比较公开资料，整理结论和引用，再决定要不要存回知识库。

STUDY

根据已有笔记学习

整理学习路径、生成练习，回到真正没有掌握的地方继续补充。

WORK

把结果变成可交付文件

起草任务、日报周报和演示文稿；填写要求、选择模型和版式，预览后下载。

KNOWLEDGE

直接连接 Markdown

浏览和检索你主动选择的 Obsidian Vault。笔记仍是普通文件，不被锁进私有格式。

DAILY

补齐每天需要的信息

可选天气、系统日历、未读邮件、每日歌曲，以及公开的 GitHub 与 Hacker News 条目。

AUTOMATION

把重复整理留给计划任务

定时生成本地草稿或刷新公开信息；模型、时间和任务内容都可以在界面中查看和修改。

FILES · TOOLS · CREDENTIALS

重要的动作，说清楚再执行。

写入先预览

准备保存什么、改哪一行，会先展示出来。内容改变后需要重新确认。

工具进入系统沙箱

限制可访问的文件、网络、运行时间和输出大小，不把安全交给一段提示词。

Key 留在系统凭据库

API Key 不进入网页界面；保存 Key 也不会顺便发起模型测试或计费请求。
