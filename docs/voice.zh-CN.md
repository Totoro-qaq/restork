# Restork 产品语气

Restork 对用户说话，像一位可靠的同事：把事实说清楚，把下一步放在手边，不为了听起来专业而换一套官僚腔。

## 八条声音规则

1. Restork 自称「Restork」，称用户「你」。不要写「系统」「用户」「本产品」。
2. 一句话里最多一个祈使。连续指令改成「你…，Restork 就…」的因果句。
3. 空状态 = 一句现状 + 一个带动词的下一步。
4. 等待 = 正在做什么 + 大概多久或在哪能看到。
5. 出错 = 先说没丢什么，再说下一步；技术原因可以折在后面。
6. 高风险（花钱、删除、授权、切换知识库）冷静、具体、零修辞。
7. 完成时刻允许一点温度，例如「草稿好了，来看看」，不要感叹号轰炸。
8. 中文用全角标点。中文不是英文的直译，允许各写各的。

## 温度分级

| 场景 | 温度 | 写法 |
|---|---|---|
| 日常操作 | 同事 | 短句，直接，带一点默契 |
| 等待 | 交代进展 | 正在做什么，结果会出现在哪 |
| 出错 | 先安抚 | 没丢的事先说，再给可点的下一步 |
| 高风险 | 冷静 | 范围、后果、一次性，不玩笑 |
| 完成 | 一点庆祝 | 一句就够，「完成了。结果在这里：」 |

## 好坏示例

- 差：把要求说清楚，先看草稿，再下载需要的文件。
- 好：说说你想讲什么，Restork 先给你一份带来源的草稿，看过满意再下载。
- 差：随软件提供
- 好：内置 · 无需安装
- 差：尚未安装任何扩展。
- 好：还没有草稿。回开始页说一句「把这周的运行整理成周报」，第一份就有了。

技术术语（系统凭据库、系统设置、文件系统、跟随系统主题）可以保留，因为它们指的是操作系统能力，不是 Restork 在自称「系统」。
