# Restork 面向谁，以及为什么值得继续做

## 一句话

Restork 是把查资料、学知识和推进工作放在一起的本地桌面工作台。它不以“陪你聊天”为终点，
而是把一次任务留下的资料、过程和结果整理成之后还能继续使用的东西。

## 最先服务的三类人

### 独立开发者与工程师

他们每天在代码、文档、GitHub 项目、技术文章和会议记录之间切换。Restork 最有价值的不是再给一个
聊天框，而是把技术调研、学习计划、任务清单、日报周报和演示文稿串在同一条可回看的运行记录里。

### 研究者、学生与长期学习者

他们需要区分“模型说了什么”和“来源实际写了什么”，也需要把零散笔记变成复习材料。Restork 的
Research 保留出处，Study 从用户主动选择的知识库出发，结果可以先预览，再决定是否保存。

### 产品、咨询和其他知识工作者

他们需要从资料中形成计划、汇报和交接，但不希望每次换一个工具就重新解释背景。Restork 适合把
多次任务、模板和明确保留的记忆接起来，同时让敏感文件继续留在本机。

## 不和谁正面争夺

Restork 不应把自己包装成“模型最多的聊天客户端”，也不靠功能数量和 Hermes、Codex、ChatGPT、
Obsidian 或 Notion 比输赢。它们分别擅长通用对话、编程、笔记和协作。Restork 应守住自己的交叉点：

- 一句话发起需要几分钟完成的任务，而不是只追求即时回复；
- 任务会经过来源、步骤、待确认事项和交付物；
- 本地文件是普通文件，不被锁进产品数据库；
- 模型、Skill、MCP、自动化和演示模板都可以替换，但安全和记录方式不随扩展变化；
- 下载后的普通用户不需要安装编译器、脚本运行时或基础 Skill。

## “和用户一起进化”应该落在哪里

“进化”不能只是一句口号，应当能被用户看见、修改和撤销：

1. **偏好会积累**：常用模型、最近版式、称呼、语言和明确启用的记忆可以继续使用。
2. **能力可替换**：Provider、Prompt、Skill、MCP、自动化与演示模板有清楚的来源、版本、启用状态和权限。
3. **结果可复用**：一次调研可以变成学习材料、任务、周报或演示文稿，不必重新粘贴上下文。
4. **改错有出口**：记忆能纠正，扩展能禁用，用户模板能软删除和恢复，更新能拒绝或回滚。
5. **默认能力不收使用税**：报告、PPTX/PDF、基础模板、三平台桌面壳和更新提醒随安装包提供。

## 可以形成长期竞争力的四件事

### 1. 文件写入值得信任

不是泛泛说“安全”，而是每次准备改什么都能先看到；确认只对应当前内容；工具的文件、网络、时间和
输出范围由操作系统和 Core 限制。

### 2. 一件事可以持续推进

连接断了可以按事件游标续上，任务身份不依赖一次 HTTP 请求；中途等待确认或失败后，仍能知道做到
了哪里。这比“回复得像不像人”更适合长期研究和工作。

### 3. 交付物质量可比较

报告、演示文稿、学习材料不能只判断“生成成功”。应持续记录用户是否采用、修改了多少、模板是否
复用、来源是否完整。能重复评估的质量，才会随着版本真正变好。

### 4. 下载和扩展都不折腾用户

macOS、Windows、Linux 提供完整安装包；模型 Key 进入系统凭据库；基础能力随包提供。扩展市场可以
丰富能力，但不能把“装十个依赖才能开始”变成产品的一部分。

## 推广时先找谁

第一轮不追求泛流量，优先邀请能给出具体反馈的人：

- Obsidian 社区里会维护长期 Markdown 知识库的开发者和研究者；
- LocalLLaMA、本地优先软件和隐私工具社区；
- 做 AI Agent、MCP、桌面工具和开发者体验的开源作者；
- V2EX、掘金、知乎上愿意讲真实工作流的工程师；
- Hacker News 放在签名下载、首次配置和英文演示稳定之后。

请高 Star 项目作者给建议时，不要泛问“如何涨 Star”，而是附上一个 60 秒演示和三个具体问题：

1. 第一次打开时，哪一步让你犹豫？
2. 这个项目和普通本地 Agent 的差异是否能在一分钟内看懂？
3. 如果只能保留一个工作流，你认为哪个最值得继续打磨？

## 接下来用什么指标判断方向

- 首次启动到成功完成第一个 Run 的时间；
- 选择知识库和保存 API Key 时的退出率；
- Run 完成率、恢复率和待确认超时率；
- 结果保存、下载或再次使用的比例；
- 一周后仍会再次打开的人数；
- 用户新增/修改模板、Skill、自动化和模型配置的比例；
- 安装失败、更新失败和必须阅读终端教程的次数。

Star 是分发结果，不是产品价值本身。先让少量目标用户顺利完成真实工作，再用演示、复盘和可下载
版本把这件事传播出去。
