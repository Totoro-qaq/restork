# Obsidian community draft

**Title:** Restork: a local-first agent workspace that keeps your Vault as ordinary Markdown

Restork connects an existing Obsidian Vault to Research, Study, and planning/report workflows
without copying the Vault into the source repository or replacing Markdown with a proprietary
knowledge store.

Vault access is opt-in and read-only by default. Files are selected explicitly, their context and
destination are previewed, and any write is tied to exact content, a one-use approval, and a
recovery record. Weather, calendar, music, location, and model providers all stay off until chosen.

The project is a bilingual Tauri/Rust desktop application under MIT. It does not require an Obsidian
plugin for the base workflow, so notes remain usable when Restork is not running. A small companion
plugin may come later if it makes opening and linking notes more convenient.

Source and setup: https://github.com/Totoro-qaq/restork
