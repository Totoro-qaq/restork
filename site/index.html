One research task, end to end

From a question to a note you can use.

This public demo uses synthetic names and content. It follows the same four decisions you see in the desktop app.

  1. 01

    Describe what you need to learn

    Choose Research and write the outcome in plain language. Restork keeps the task separate from casual chat.

  2. 02

    Follow sources and progress

    See which stage is active, what was found, and when a provider or tool needs another attempt. Stop remains available.

  3. 03

    Review the exact write

    Before a Markdown file changes, Restork shows the destination and proposed content. Approval applies once to that exact version.

  4. 04

    Keep an editable result

    The result is an ordinary local note. The same work area can also draft daily or weekly reports and export PPTX, PDF, or Markdown.

What the software actually does

Trust the mechanism, not a slogan.

Files stay ordinary
Use an existing Obsidian Vault or another folder. Markdown remains readable without Restork.
Credentials stay native
Provider keys are saved through the operating system credential store and are not exposed to browser JavaScript.
Writes need a fresh review
Each approval is single-use and bound to the exact content shown on screen.
Tools have OS limits
MCP processes use macOS Seatbelt, Linux bubblewrap, or Windows Job Objects, with time and output limits.
Updates stay optional
Stable is the default channel. Checks run at most daily, can be dismissed or disabled, and never restart the app silently.
