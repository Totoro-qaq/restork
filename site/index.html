YOU SEE THE CHANGE FIRST

Preview before every write.

Restork lays out the exact change before it touches a real note. Your approval applies once, to that version only.

01

Markdown stays ordinary

Point Restork at an existing Obsidian Vault or a separate folder. Notes never become a proprietary database; the durable home remains local files.

02

See the change before it lands

Research and Study notes appear as a preview first. One approval applies to the exact change on screen, with no silent overwrite.

03

MCP runs in a real sandbox

Tool calls run inside platform-native isolation — macOS Seatbelt, Linux bubblewrap, Windows Job Objects — with strict time, network, and output limits.

04

Reasoning is a setting, not a leak

Choose DeepSeek, GLM, Kimi, Qwen, Ollama, or OpenRouter. Only supported reasoning levels appear; private chain-of-thought is not displayed or retained.

05

You can see what happened

Runs keep a readable history of tool results, retries, approvals, and saved progress. Stop one midway and continue without starting from zero.

06

The app cleans up after itself

The Rust desktop shell starts Core, checks that it is healthy, and closes the whole process tree when you quit.

INSTALLATION AND UPDATES

Connect a Vault and model when you are ready.

Every package includes the Rust Core and Dashboard. Choose a Vault and model provider when you are ready; saving a key uses your system credential store and never starts a paid test on its own. Refresh the browser or reopen the app and Restork reconnects to the local session. Interrupted runs continue from the last event received. Alpha downloads are clearly marked as unsigned and include checksums and build records you can verify.

Signed releases will surface updates inside the app: no check on the first launch, then at most once a day. Restork only notifies; it does not silently download or restart. Stable is the default and Beta is opt-in. You can dismiss one version or turn automatic checks off entirely.

Restork is free and open source for researchers, developers, and knowledge workers. Review important results yourself. Read the usage notes and security policy.
