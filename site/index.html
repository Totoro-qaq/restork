Build prerequisites, practice without answer leakage, and revisit what you actually missed.

THE PRODUCT, NOT A MOCKUP

Watch a governed run.

This public recording uses synthetic data and makes no live model request.

01

Markdown stays ordinary

Use an existing Obsidian Vault or a separate folder. Restork does not turn your notes into a proprietary database.

02

Reasoning is a real setting

Choose DeepSeek, GLM, Kimi, Qwen, Ollama, OpenRouter, or a compatible endpoint. Only supported intensity levels appear.

03

Effects are reviewable

Typed policy, preview hashes, one-use approvals, event history, and file checkpoints live outside prompt text.

04

Desktop lifecycle is owned

The Rust shell selects a port, supervises Core, checks heartbeats, and terminates its complete process tree.

FIVE-MINUTE SOURCE START

Explore first. Connect things later.

git clone https://github.com/Totoro-qaq/restork.git
cd restork
./scripts/quickstart.sh

Open the printed loopback URL and enter the one-time pairing code. The offline path needs no API key and reads no Vault.
