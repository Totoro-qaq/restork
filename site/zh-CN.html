RESTORK CORE · 127.0.0.1

一个 CORE，串起一天的事情

研究、学习和工作，本来就会交织在一起。

R

Research

比较公开来源、保留证据，并在存入 Vault 前审一份带引用的 Markdown 笔记。

S

Study

以你的笔记为前提整理学习路径，练习不漏答案，再回去补真正漏掉的地方。

W

Work

把有限目标整理成计划、日报周报、演示文稿或脱敏交接，并保留可恢复产物。

◐

每日上下文

天气、一个本地 ICS 日历，以及来自 QQ 音乐、网易云、Apple Music 或私有歌单的每日单曲。

◇

Radar

在你主动开启后发现 GitHub 上公开的 AI/Agent 项目并收录 Hacker News，由 Core 排序和缓存。

✉

邮件感知

macOS 上看未读邮件的主题与发件人，但账号凭据和邮件正文都不会传给模型。

∿

运行轨迹

按迭代折叠显示 token、工具成败、重试与审批——看懂一次运行，不用逐条读事件。

写入前先问你

每次写入都先预览。

一个会偷偷写文件的 Agent 是没法拿来碰真实笔记的。Restork 会先把具体改动展示给你；你确认的只会是眼前这一次改动。

01

Markdown 仍是普通文件

指向你现有的 Obsidian Vault 或另选一个目录。笔记不会被锁进私有数据库，本地文件始终是真正的归宿。

02

每次写入都先审

Research 与 Study 笔记会先以预览呈现，你批准后通过一次性、绑定具体内容的审批写回。没有静默覆盖，没有自动执行。

03

MCP 跑在真沙箱里

工具调用运行在平台原生沙箱后——macOS Seatbelt、Linux bubblewrap、Windows Job Objects——I/O 受限，而不是靠提示词级别的安全。

04

思考是设置，不是泄漏

可选 DeepSeek、GLM、Kimi、Qwen、Ollama、OpenRouter。界面只显示该模型真正支持的思考档位；私有思维链不展示、不留存。

05

运行可观测

事件持久化、迭代折叠的运行视图、带内容的检查点——一次运行可以被打断、恢复、回看，而不丢工作。

06

桌面生命周期由 Rust 管理

自动选端口、启动 Core、检查心跳，并在退出时回收完整进程树。

无需编译环境

先下载，准备好时再连接自己的东西。

macOS   · DMG
Windows · 安装 EXE 或 MSI
Linux   · AppImage 或 DEB

每个安装包都内置 Rust Core 与 Dashboard。首次清单允许以后再选 Vault 和 Provider；Key 由原生凭据库接收，保存时不会自动发起付费测试。Alpha 文件会明确标注未签名，并附校验和、SBOM、来源证明与干净 runner 生命周期证据。
