免费开源 · 本地文件 · MIT

查资料，学知识，推进工作。

Restork 可以查找公开资料、整理本地 Markdown、安排学习和推进手头的工作。 要改文件时，它会先把具体内容列出来；你确认后才保存。

下载桌面技术预览 从源码构建

预编译 DMG、MSI/EXE、AppImage 与 DEB，无需编译器。它们会明确提示未签名；首次启动也不会自动开启模型、Vault、天气、日历或定位。

只在你的电脑上运行

无需编译环境

选择你的系统，下载后直接安装。

一天里的几种事情

研究、学习和工作，本来就会交织在一起。

R

Research

比较公开资料、记下出处，再决定要不要把整理好的 Markdown 笔记存进 Vault。

S

Study

以你的笔记为前提整理学习路径，练习不漏答案，再回去补真正漏掉的地方。

W

Work

把具体目标整理成计划、日报周报、演示文稿或脱敏交接。报告和演示文稿支持填写要求、六套内置版式、逐页预览，并直接下载 PPTX、PDF 或 Markdown，不需要另装运行环境。

◐

每日上下文

天气、一个本地 ICS 日历，以及来自 QQ 音乐、网易云、Apple Music 或私有歌单的每日单曲。

◇

Radar

在你主动开启后发现 GitHub 上公开的 AI/Agent 项目并收录 Hacker News，由 Core 排序和缓存。

✉

邮件感知

macOS 上看未读邮件的主题与发件人，但账号凭据和邮件正文都不会传给模型。

∿

运行记录

按步骤查看 token、工具成败、重试与确认——想知道刚才发生了什么，不必翻完整日志。

写入前预览

保存前看清具体内容。

Restork 会先展示准备写入的内容。这次确认只对应眼前这份改动；内容变了，需要重新确认。

01

Markdown 仍是普通文件

指向你现有的 Obsidian Vault 或另选一个目录。笔记不会被锁进私有数据库，本地文件始终是真正的归宿。

02

保存前确认

Research 与 Study 笔记会先以预览呈现。一次确认只对应当前内容，不会悄悄覆盖文件。

03

MCP 跑在系统沙箱里

macOS Seatbelt、Linux bubblewrap 与 Windows Job Objects 会限制工具能访问什么、能运行多久，不靠一段提示词碰运气。

04

思考是设置，不是泄漏

可选 DeepSeek、GLM、Kimi、Qwen、Ollama、OpenRouter。界面只显示该模型真正支持的思考档位；私有思维链不展示、不留存。

05

过程可以回头看

调用过哪些工具、哪里重试、你确认了什么，都能回头查看。中途停下，也能接着做。

06

打开就用，退出不留后台

Rust 桌面程序会自动启动并照看 Core；退出 Restork 时，相关进程会一起关闭。

安装与更新

准备好时，再连接自己的知识库和模型。

每个安装包都带有 Rust Core 与 Dashboard。Vault 和模型都可以以后再连；API Key 存进系统凭据库，保存时不会自己发起付费测试。刷新浏览器或重新打开应用后，Restork 会接回本地会话；运行中断时，也会从上一条收到的事件继续。Alpha 下载会清楚标出未签名，并附校验和与构建记录，方便你核对来源。

正式签名版会在应用里提醒更新：首次启动不检查，之后最多每天一次；只提醒，不会自己下载或重启。Stable 是默认通道，Beta 需要主动加入。你可以关闭当前版本的提醒，也可以在设置里完全关闭自动检查。

Restork 免费开源，面向研究者、开发者与知识工作者；重要结果请自行复核。请阅读使用说明与安全政策。
