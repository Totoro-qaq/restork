RESTORK CORE · 127.0.0.1

一个 CORE，三种前进方式

适应一天里真正交织的事情。

R

Research

比较论断、保留证据，并在保存前审查一份带引用的 Markdown 笔记。

S

Study

梳理前置知识，在没有答案泄漏的情况下练习，再复习真正出错的地方。

W

Work

把有限目标整理成计划、日报周报、演示文稿或脱敏交接，并保留可恢复产物。

真实产品，不是概念图

看看一次受控运行。

这段公开演示只使用合成数据，也不会发起真实模型请求。

01

Markdown 仍是普通文件

接入已有 Obsidian Vault，或另选一个目录。Restork 不会把笔记锁进私有数据库。

02

思考强度是明确设置

可选 DeepSeek、GLM、Kimi、Qwen、Ollama、OpenRouter 或兼容端点；界面只显示支持的档位。

03

副作用先审查

类型化策略、预览哈希、一次性审批、事件记录与文件检查点都在 Prompt 之外。

04

桌面生命周期由 Rust 管理

自动选端口、启动 Core、检查心跳，并在退出时回收完整进程树。

五分钟源码体验

先看看，再决定连接什么。

git clone https://github.com/Totoro-qaq/restork.git
cd restork
./scripts/quickstart.sh

打开终端打印的本地地址并输入一次性配对码。查看本地工作台不需要 API Key；模型任务需要你明确配置 Provider，也只有在你主动选择后才会读取 Vault。
