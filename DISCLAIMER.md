# Why Restork exists, and what to expect

Restork is a free, open-source project built to help researchers, developers,
and knowledge workers get useful work done with files they control. Official
Restork releases do not require a subscription or a paid Restork account.
Community participation, bug reports, documentation, and code contributions
are welcome.

This page explains what the project can and cannot promise. The
[MIT License](LICENSE) remains the legal license and permits downstream use,
modification, redistribution, and commercial distribution. This page does not
replace the license or create a warranty.

## What maintainers provide

- Public source code, release notes, checksums, and the security controls that
  can be reasonably tested for supported releases.
- Best-effort review of reproducible bugs and privately reported security
  vulnerabilities, with fixes or mitigations prioritized by impact.
- Honest descriptions of experimental, platform-specific, unavailable, and
  third-party-dependent features.
- A local-first architecture that keeps durable Markdown and credentials under
  the user's control instead of operating a hosted Restork account service.

Restork is a community project, not a commercial support service. There is no
guaranteed response time, uptime commitment, service-level agreement, or
promise that every platform, model, dependency, or feature will remain
available forever.

## What users remain responsible for

AI output can be incomplete, outdated, misleading, or wrong. Review important
research, code, reports, citations, file changes, and decisions before relying
on or approving them. Restork is not a substitute for professional legal,
medical, financial, safety, or security advice.

Before using Restork with valuable work:

- keep independent backups and test recovery;
- use scoped and revocable API keys, provider budgets, and account controls;
- review outbound context, tool permissions, file diffs, and approvals;
- follow applicable law and the terms of any model, data source, music service,
  MCP server, operating system, or other third party; and
- never use Restork for unauthorized access, surveillance, abuse, malware, or
  harm to another person or system.

## Providers, extensions, and other third parties

Optional cloud providers receive only the context a user chooses to send, but
their processing, retention, availability, billing, and security are governed
by their own policies. The same is true of community Skills, plugins, MCP
servers, package registries, operating-system services, and imported data.

Restork maintainers do not operate or control those services and cannot promise
their correctness, availability, security, pricing, or continued compatibility.
Review an extension and its requested permissions before enabling it.

## Security incidents

No software, sandbox, dependency tree, or AI system can be guaranteed free of
vulnerabilities. If a key or private file may have been exposed, stop the
affected version, revoke or rotate the credential with its provider, preserve
non-sensitive diagnostic details, and follow [SECURITY.md](SECURITY.md). Do not
post credentials, private notes, work artifacts, or exploit details publicly.

Maintainers will assess confirmed reports and provide a fix, mitigation, or
clear warning on a best-effort basis. This commitment is not a guarantee that
unknown defects will be discovered before harm occurs.
